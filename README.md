# Business Logic Testing with JUnit

## 📌 Жоба сипаттамасы

Бұл жоба Java тілінде жазылған бизнес логиканы JUnit көмегімен тестілеуді көрсетеді.
Негізгі мақсат — `StudentService` сияқты кластардағы логиканың дұрыс жұмыс істейтінін тексеру.

---

## 🎯 Мақсаты

* Бизнес логиканың дұрыстығын тексеру
* Қателерді ерте анықтау
* Кодтың сенімділігін арттыру
* Бағдарламаның сапасын жақсарту

---

## 🧪 Бизнес логиканы тестілеу деген не?

Бизнес логиканы тестілеу — бағдарламаның негізгі функцияларының дұрыс жұмыс істейтінін тексеру.

Мысалы:

* Студент қосу
* Студентті табу
* Студентті өшіру

Осылар дұрыс нәтиже беруі керек.

---

## 🔍 Тест сценарий деген не?

**Тест сценарий** — бағдарламаны тексеретін нақты жағдай (case).

### Мысалдар:

* Студент қосу → сәтті қосылуы керек
* ID арқылы студентті табу → дұрыс студент қайтуы керек
* Студентті өшіру → тізімнен жойылуы керек
* Жоқ студентті іздеу → null немесе қате қайтаруы керек

👉 Әр сценарий бір логиканы тексереді

---

## ❗ Қателер қалай анықталады?

JUnit тесттер арқылы қателерді анықтайды.

Егер:

* Күтілетін нәтиже ≠ нақты нәтиже → ❌ ҚАТЕ (FAIL)
* Күтілетін нәтиже = нақты нәтиже → ✅ ДҰРЫС (PASS)

JUnit қай тест өтпегенін көрсетеді.

---

## 🧠 assert деген не?

`assert` — нәтижені тексеретін команда.

### Негізгі түрлері:

* `assertEquals(expected, actual)` → теңдігін тексереді
* `assertTrue(condition)` → true екенін тексереді
* `assertFalse(condition)` → false екенін тексереді
* `assertNull(object)` → null екенін тексереді

### Мысал:

```java
assertEquals("John", student.getName());
```

👉 Егер нәтиже сәйкес болмаса → тест өтпейді

Бұл қателерді ерте табуға және бағдарламаны тұрақты етуге мүмкіндік береді.
